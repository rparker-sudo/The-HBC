Add a whole season from a spreadsheet

Build your schedule in Excel or Google Sheets using the template columns, select the cells (including the header row), copy, and paste below. For weekly practices, fill in repeat_until with the last date and the event will repeat every week on the same weekday.

How the schedule builder works

  1. Season phases: label your three phases and set their dates. Add holidays so no practices land on them.
  2. Gyms & courts: add each gym, its number of courts and the times you can use it (times can be different per phase).
  3. Coaches and teams: give each team its coaches, practices per week, practice length and court needs. Mark a team as a set schedule if its times are already decided.
  4. Special rules: add anything the schedule must or should follow.
  5. Court priority: put every court in the order to use it. Any team can have its own order, and can mark courts it should never use.
  6. Generate. Each flexible team's times are written into its listing, where you can change any day, time, gym or court. Use Lock as set schedule to keep a team's times when you generate again.
  7. Check the weekly preview (clashes show in red), then Add to calendar.
  8. On the Calendar tab, click any practice to change just that practice, or that practice and all future ones.
  9. Click Publish to website to make everything live.

A coach is never booked in two places at once, and a court never holds more than one full-court team (or two shared-court teams) at a time. Conflicts are shown in red on the calendar.

Getting your access key (one time)

  1. Sign in to GitHub as rparker-sudo and open github.com/settings/personal-access-tokens/new.
  2. Name it HBC Calendar and pick an expiration (for example, 1 year).
  3. Under Repository access, choose Only select repositories and pick The-HBC.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it (it starts with github_pat_) and paste it above.

Treat the key like a password: it can change the website's files. Anyone else who helps with the schedule can make their own key the same way from an account with access to the repository.
